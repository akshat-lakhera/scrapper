Triggering Custom Collectors

To initiate a collection run on a custom Scraper Studio collector, send an authenticated POST request to the DCA trigger endpoint.

The collector will render the page using unblocking proxies, solve CAPTCHAs, and execute AI-synthesized parser rules.

bdata scraper run c_mpohus372o5tmid1jk "https://example.com/target"
