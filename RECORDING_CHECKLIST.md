# Demo Recording Checklist

Follow these standards to ensure a clean video presentation:

---

### 1. Environment & Display Preparation
- [ ] Browser resolution set to **1080p (1920x1080)** or **1440p**.
- [ ] Browser zoom set to 100% (or 110% for crisp typography).
- [ ] Backend running on single-port mode (`http://127.0.0.1:8000/`).
- [ ] Close all unrelated browser tabs, bookmarks bars, and notifications.
- [ ] Ensure `.env` or sensitive API keys are NOT visible on screen.

---

### 2. Audio & Video Quality
- [ ] Clear microphone input with background noise cancellation enabled.
- [ ] Screen recording at **60 FPS** to capture fluid spring transitions and particle physics.
- [ ] Cursor highlighted or smooth cursor tracking enabled.

---

### 3. Key Video Milestones
- [ ] **0:00** — Opening Overview page with live metrics and Bright Data status badge.
- [ ] **0:45** — Product extraction on live URL with raw JSON drawer toggle.
- [ ] **1:30** — Job intelligence extraction with salary & location badges.
- [ ] **2:15** — 3-Stage Self-Healing diagnosis, approval, and verification.
- [ ] **3:00** — Monospace Audit Log and translucent JSON modal inspection.
